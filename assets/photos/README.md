## Publicación (GitHub web) — completada

1. Descargar y **descomprimir** el paquete privado `TORREMOLINOS_FOTOS_LISTAS_GITHUB_v1.zip` creado en ChatGPT.
2. Entrar en [assets/photos/](./assets/photos/) del repositorio.
3. Seleccionar **Add file → Upload files**.
4. Seleccionar los **ocho archivos .webp** que están en `assets/photos/` del paquete (no subir el ZIP intacto).
5. Confirmar el commit en `main`.
6. Comprobar GitHub Actions y abrir la página pública en un navegador.

El sitio utilizará las fotografías automáticamente en cuanto estén disponibles. No es necesario editar CSS ni HTML.
