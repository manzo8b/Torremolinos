**Estado:** autorización confirmada para las fotografías del autor que son paisajes y no muestran primeros planos reconocibles. **Los archivos WebP siguen pendientes de subir a GitHub.**

## Lo que ya está preparado

La portada reconoce automáticamente dos imágenes:
- `assets/photos/hero-torremolinos-desktop.webp`
- `assets/photos/hero-torremolinos-mobile.webp`

La galería `La ciudad desde dentro` se activa cuando encuentra estas otras tres:
- `assets/photos/playa-palmeras-panorama.webp`
- `assets/photos/el-bajondillo-letrero.webp`
- `assets/photos/paseo-palmeras.webp`

La selección incluye además otras tres escenas opcionales: `mar-mediterraneo.webp`, `costa-torremolinos.webp` y `paseo-centro.webp`.

Sin estos archivos, **la portada conserva la imagen original de Wikimedia Commons y la galería personal permanece oculta**, evitando fotos rotas.

## Publicación (GitHub web)

1. Descargar y **descomprimir** el paquete privado `TORREMOLINOS_FOTOS_LISTAS_GITHUB_v1.zip` creado en ChatGPT.
2. Entrar en [assets/photos/](./assets/photos/) del repositorio.
3. Seleccionar **Add file → Upload files**.
4. Seleccionar los **ocho archivos .webp** que están en `assets/photos/` del paquete (no subir el ZIP intacto).
5. Confirmar el commit en `main`.
6. Comprobar GitHub Actions y abrir la página pública en un navegador.

El sitio utilizará las fotografías automáticamente en cuanto estén disponibles. No es necesario editar CSS ni HTML.
